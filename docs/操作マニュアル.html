はじめに

1.1本書について

本書は、顧問先ごとの法定手続き（算定基礎届、労働保険年度更新、36協定届など）の進捗と期限を一元管理する業務進捗・期限管理SaaSの操作マニュアルです。画面ごとに、表示内容だけでなく「どのボタンを押すと何が起こるか」まで具体的に説明します。初めてお使いになる方は「2. ログインと初期設定」から順に読み進めてください。

1.2ご利用にあたっての前提

  • 本サービスは複数の社労士事務所が共通のシステムを利用するマルチテナントSaaSです。他事務所のデータが閲覧・混在することは構造的にありません。
  • アカウントには「オーナー（所長・管理者）」と「スタッフ（担当者）」の2種類があり、操作できる範囲が異なります（詳細は13章）。
  • 推奨環境：Google Chrome または Microsoft Edge の最新版。スマートフォン・タブレットでも閲覧可能ですが、書類のアップロードやカレンダー編集はPCでの操作を推奨します。
  • 利用できる機能（Excel移行・PDFレポート・計算アシスタント・カスタムフィールド等）は事務所ごとに運営者が設定しています。本書に記載の機能がサイドバーに見当たらない場合は、運営者までお問い合わせください。

1.3画面全体の構成

ログイン後は画面左側のサイドバーから各機能へアクセスします。サイドバーの主なメニューは以下のとおりです。

ログインと初期設定

事務所のオーナーアカウントは、運営者による契約手続き時に発行されます。スタッフのアカウントはオーナーが「ユーザー管理」画面から追加してください（13章参照）。

  1. 1発行された事業所ID・ユーザーID・パスワードでログイン画面からログインします。ログインボタンを押すと、入力内容が正しければダッシュボード画面へ遷移します。事業所ID・ユーザーID・パスワードのいずれかが誤っている場合は、どの項目が誤っているかを特定できないよう、共通のエラーメッセージが表示されます（不正アクセス対策）。
  2. 2初回ログイン後、画面右上のアカウントメニューからプロフィールを開き、氏名・メールアドレス・パスワードを必要に応じて変更してください。更新するを押すと即座に反映され、画面右下に完了メッセージが一瞬表示されます。
  3. 3期限通知をブラウザのプッシュ通知でも受け取りたい場合は、サイドバー下部の通知トグルから許可を行ってください（8章参照）。

3

ダッシュボード

ログイン後、最初に表示される画面です。事務所全体の進捗状況を俯瞰できます。

3.1表示される情報

  • 期限サマリ：「期限超過」「7日以内」「30日以内」の3つのカードに、未完了タスクの件数が表示されます。カードをクリックすると、該当するタスクだけに絞り込んだ一覧画面に自動的に遷移します。
  • ステータス別件数：未着手／進行中／書類収集済／提出済／完了の5区分で、タスクの件数をバッジ表示します。
  • 担当者別ワークロード：担当者ごとの未完了タスク件数を横棒グラフで表示し、期限超過分は赤色で内訳表示します。担当者名をクリックすると、その担当者のタスク一覧に絞り込めます。
  • 手続き種別ごとの内訳：どの手続きが多く滞留しているかを横棒グラフで確認できます。項目をクリックすると該当する手続き種別のタスク一覧へ絞り込んだ状態で遷移します。
  • 期限が近いタスク：直近8件を、顧問先名・手続き名・期限日・ステータス・担当者とともに一覧表示します。行をクリックするとタスク詳細画面に移動します。
活用のヒント
朝一番にダッシュボードを開き、「期限超過」件数がゼロであることを確認する運用にすると、期限漏れの早期発見につながります。

4.3対象手続き（購読設定）

顧問先の編集画面下部に「対象手続き」セクションがあります。ここでカテゴリ別にチェックボックスで手続き種別を選択し、保存すると、選択した手続きが以後この顧問先向けに自動でタスク生成される対象になります。新規に顧問先を登録したら、必ずこの設定を行ってください。

4.4顧問先の編集・削除

  • 編集：顧問先一覧から対象行をクリックし、編集画面で各項目を修正して保存するを押します。保存後は一覧画面へ戻り、編集した行がハイライト表示されます（新規登録時と同じ挙動）。
  • 削除：編集画面の削除ボタンから行います。押すと確認モーダルが表示され、「削除する」を選ぶまでは実際には削除されません。削除は取り消せません。削除操作はオーナーのみ実行できます。

4.5Excelエクスポート・インポート

一覧画面から現在の顧問先データをExcel（xlsx）またはCSV形式で書き出せます。Excelで管理していたデータを本サービスへ取り込みたい場合は「11. Excelデータの移行」を参照してください。

「タスク」は、ある顧問先について、ある手続き種別を、いつまでに対応するかという個別の案件です。自動生成バッチにより、対象手続きに設定された周期に沿って自動的に作成されるほか、手動でも追加できます。

6.1タスク一覧

  • ダッシュボードの各カードやカレンダーからも、絞り込み済みの状態でこの一覧に遷移できます。

6.2タスクの新規作成

一覧画面右上の新規作成から、顧問先・手続き種別・タイトル・期限日・担当者・メモを入力して作成します。期限日は画面を開いた時点で本日の日付が初期値として入力済みのため、実際の期限日に変更したうえで登録してください。自動生成の対象外の単発案件（顧問先からの個別依頼など）を管理したい場合にご利用ください。

作成するを押すと、作成したタスクがタスク一覧に反映され、期限日順で該当のページへ自動的に切り替わったうえで、そのタスクの行がハイライト表示されます。

6.3タスク詳細画面

顧問先・手続き種別・期限日（期限超過は赤字で強調表示）・現在のステータスを確認できます。自動生成時の期限から日付を修正した場合は「元の期限：〇〇」として表示され、変更履歴が分かるようになっています。

編集できる項目（担当者本人またはオーナーのみ）：

  • 期限日
  • ステータス（未着手／進行中／書類収集済／提出済／完了）
  • 担当者
  • メモ（マイナンバーらしき文字列は警告表示されます）
  • カスタムフィールドの値

保存するを押すと、変更元の画面（タスク一覧・カレンダー等）へ戻ります。一覧に戻る場合は編集した行がハイライト表示されます。

注意
自分が担当者から外れると、それ以降そのタスクは編集できなくなります（閲覧のみ可能）。担当変更の際はご注意ください。

6.4書類チェックリスト

タスク詳細画面内で、必要書類の収集状況を管理できます。

  1. 1追加から、書類名・必須かどうか・保存年数を入力して項目を追加します。押すとその場でチェックリストに1行追加されます。
  2. 2書類を受領したらファイルを選択からファイルをアップロードします（対応形式：PDF／JPG／PNG／Word／Excel、最大10MB）。アップロードが完了すると、ファイル名がリンク表示に変わります。
  3. 3収集チェックをONにすると、受領日と、保存年数から自動計算された保存期限が記録されます。
  4. 4アップロード済みファイルはファイル名のリンクからダウンロード可能です（閲覧・ダウンロードは記録として保存されます）。
個人情報保護について
書類ファイルは暗号化されたストレージに保存され、ダウンロードのたびに有効期限付きの一時URLが発行されます。保存期限が過ぎた書類は自動削除されず、オーナーへ通知が届きますので、内容を確認のうえ手動で削除してください（誤削除防止のための仕様です）。

8

通知（期限アラート）

期限漏れを防ぐため、設定されたタイミングで自動的に通知が届きます。通知先は担当者（未割当の場合は事務所のオーナー全員）です。

8.1メール通知

登録済みのメールアドレス宛に、常に自動送信されます。特別な設定操作は不要です。

8.2ブラウザのプッシュ通知（Web Push）

ブラウザを閉じていても、パソコンの通知センターにOS標準の通知として届く機能です。サイドバーの通知トグルから有効化してください。

  1. 1サイドバーの通知アイコン（トグル）をクリックします。
  2. 2ブラウザから通知の許可を求められるので「許可」を選択します。トグルがON表示に変わります。
  3. 3以降、設定した通知タイミングでブラウザ通知が届きます。不要になった場合は同じトグルから解除できます（OFFにするとその場で購読が解除されます）。

8.3デスクトップ常駐アプリでの通知

ブラウザを起動していなくても、パソコンにインストールした専用アプリが常駐し、OS通知センターに直接通知を表示する機能です（Windows／Mac／Linux対応）。以下、設定画面での操作からアプリのインストール・初期設定まで、順を追って説明します。

8.3.1　アクセストークンの発行（Web側の操作）

  1. 1画面右上または左下のアカウントメニューからデスクトップ通知アプリを選び、設定画面を開きます。
  2. 2トークンを発行するボタンを押します。確認は不要で、押すと即座に新しいトークンが発行されます。
  3. 3発行された平文のトークン文字列が画面に一度だけ表示されます。この画面を離れると二度と表示されないため、必ずこの時点でコピーしてください（コピーし忘れた場合は再発行が必要です。8.3.4参照）。

8.3.2　インストーラーのダウンロード

同じ画面の「1. アプリをダウンロードしてインストールする」セクションから、お使いのパソコンのOSに応じたインストーラーをダウンロードします。

  • Windows：「Windows用をダウンロード」ボタンから .msi ファイルをダウンロードします。
  • Mac：「Mac用をダウンロード」ボタンから .dmg ファイルをダウンロードします。
  • Linux：「Linux用をダウンロード」ボタンから .AppImage ファイルをダウンロードします。

アクセスした端末のOSが自動判定され、該当するボタンがハイライト表示（「お使いのPC向け」）されます。開発ツールのインストールなどは不要で、ダウンロードしたインストーラーを実行するだけでセットアップが完了します。

8.3.3　インストールとアプリ初回設定

  1. 1ダウンロードしたインストーラーを実行します（Windowsは.msiをダブルクリック、Macは.dmgをマウントしてアプリをApplicationsフォルダへドラッグ、Linuxは.AppImageに実行権限を付与して起動）。
  2. 2インストール後、アプリを起動すると設定画面が表示されます。
  3. 3「事務所のURL」欄に、デスクトップ通知アプリ連携画面に表示されているURL（このページ自体のURLではなく、ドメイン部分のみのURL）を貼り付けます。
  4. 4「APIトークン」欄に、8.3.1でコピーした平文トークンを貼り付けます。
  5. 5「確認間隔」（通知を何分おきに確認しに行くか。デフォルト5分、最小1分）を必要に応じて変更します。
  6. 6「自動起動」（パソコン起動時にアプリも自動的に起動するか）を必要に応じてON／OFFします。初回起動時はデフォルトでONになっています。
  7. 7設定を保存すると、アプリはOSのタスクトレイ（Windowsは画面右下、Macは画面右上、Linuxはデスクトップ環境により異なる）に常駐アイコンとして表示され、以後バックグラウンドで通知を確認し続けます。

8.3.4　トークンの再発行・失効

デスクトップ通知アプリ連携画面には、発行済みトークンの発行日時・最終利用日時が表示されます。再発行するを押すと確認ダイアログが表示され、承諾すると新しいトークンが発行されると同時に、現在使用中の古いトークンは自動的に無効になります。再発行後は、パソコン側のデスクトップアプリの設定画面でも新しいトークンに入力し直す必要があります。

注意
トークンは他人に共有しないでください。第三者に知られた場合は速やかに再発行してください（1ユーザーにつき常に1つのトークンのみが有効です）。

Excelデータの移行

Excelで管理していた顧問先・タスクの情報を、本サービスへ取り込むための機能です。顧問先一覧・タスク一覧のそれぞれの画面から利用できます。

11.1インポートの4ステップ

  1. 1アップロード：xlsx／xls／csv形式のファイル（最大5MB）を選択し、次へ進みます。
  2. 2列マッピング：アップロードしたファイルの見出し・プレビューを見ながら、各列がどの項目（顧問先名・期限日・担当者名など）に対応するかをプルダウンで手動選択します。自動での推測は行われないため、内容を確認しながら正確に選択してください。
  3. 3確認：全行について、取り込み可能／警告あり／エラー（取り込み不可）の判定結果とプレビューが表示されます。エラーの原因（必須項目の未入力、存在しない顧問先名など）もあわせて確認できます。
  4. 4確定してインポート：ボタンを押すと、エラーのない行のみが登録されます。エラーがあった行は個別にスキップされ、後から手動で追加・修正できます。処理が完了すると結果件数（成功／スキップ）が表示されます。
権限について
インポートの実行はオーナー、またはオーナーから個別に「Excel移行ウィザード実行」権限を付与されたスタッフのみ操作できます。
個人情報保護について
メモ欄にマイナンバーらしき文字列が含まれる場合は確認画面で警告が表示されます（取り込み自体は可能です）。書類に該当するものは、インポートではなく各タスクの書類チェックリストからアップロードしてください。

13.1アカウントの追加・編集・削除

13.2権限の考え方

ユーザー編集画面で、ロールを「スタッフ」に設定すると3つの権限チェックボックスが表示されますので、必要な権限のみをオーナーが個別に付与してください。

委譲できない操作
顧問先の削除、ユーザー管理、契約・請求情報の閲覧、デスクトップ通知トークンの発行は、影響範囲が大きいためスタッフへの委譲対象外とし、常にオーナー限定（デスクトップ通知トークンは本人限定）です。
